# Lesson 05: JavaScript Loops

## Overview

In this lesson, I learned how to use loops in JavaScript to execute repetitive tasks efficiently.

As a QA Engineer, loops are useful for executing multiple test cases, checking test results, validating data, and reducing repetitive code.

I completed all practice exercises and assignments in a single JavaScript file: `lesson-05.js`.

## Topics Covered

### 1. For Loop
- Understanding the `for` loop.
- Using loops to execute repetitive tasks.
- Iterating through arrays using index values.

### 2. While Loop
- Understanding the `while` loop.
- Using conditions to control loop execution.
- Updating loop variables to avoid infinite loops.

### 3. Do...While Loop
- Understanding the `do...while` loop.
- Learning that the code block executes at least once before checking the condition.

### 4. For...Of Loop
- Iterating through arrays.
- Accessing array values directly.
- Filtering data using conditions.

### 5. Break Statement
- Stopping loop execution when a specific condition is met.

### 6. Continue Statement
- Skipping the current iteration and continuing with the next one.

### 7. Infinite Loops
- Understanding how incorrect conditions can create infinite loops.
- Learning why loop variables and conditions must be handled carefully.

## Practice Examples

I practiced JavaScript loops using real-world QA-related examples:

- Printing mobile data pack prices.
- Filtering data pack prices.
- Executing multiple test cases.
- Skipping failed test results using `continue`.
- Stopping execution at the first failed test using `break`.
- Running test cases using a `while` loop.

## QA Assignments

| Task | Description |

| Task 01 | Validate data pack prices against a maximum expected price of 200. |
| Task 02 | Execute multiple test cases using `for...of`. |
| Task 03 | Skip failed test results using `continue`. |
| Task 04 | Stop execution when the first failed test is found using `break`. |
| Task 05 | Execute five test cases using a `while` loop. |

### Task 01: Expected Logic

- Pack price less than or equal to 200 → Test Passed.
- Pack price greater than 200 → Test Failed.

## Key Learnings

- How to execute repetitive tasks using loops.
- How to iterate through arrays.
- How to control loop execution using `break` and `continue`.
- How to avoid infinite loops.
- How loops can be applied to real-world QA testing scenarios.
